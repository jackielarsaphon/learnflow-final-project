# สคริปต์อัดวิดีโอส่ง Final Project

ความยาวประมาณ 4–5 นาที ใช้โปรเจกต์ที่รันบนเครื่องของคุณ และอัดหน้าจอพร้อมเสียงอธิบายของคุณได้

เตรียมก่อนอัด: เปิดเว็บด้วย `npm run dev` ทดลองวิดีโอ กด “ล้างข้อมูลการเรียน” หากต้องการเริ่มใหม่ ปิดแท็บหรือหน้าต่างที่มีข้อมูลส่วนตัว และเปิด VS Code ไว้สำหรับโชว์ Class Model

## 0:00–0:25 — แนะนำ

แสดงหน้าหลัก แล้วพูด:

“สวัสดีครับ โปรเจกต์นี้ชื่อ LearnFlow เป็นเว็บเรียนออนไลน์ที่พัฒนาด้วย React มีหน้ารวมคอร์ส หน้ารายละเอียด และห้องเรียน ข้อมูลคอร์สดึงจาก API ที่โจทย์กำหนด และรองรับทั้งมือถือและคอมพิวเตอร์ครับ”

## 0:25–1:00 — หมวดหมู่และค้นหา

1. ชี้ให้เห็น 8 คอร์ส 4 หมวดหมู่
2. กด Programming แล้วกด Design
3. กดทั้งหมด แล้วค้นหา React
4. ล้างคำค้นแล้วเลือกเรียงตามเวลาเรียน

พูด:

“เราสามารถเลือกหมวดหมู่ได้ ระบบจะแสดงเฉพาะคอร์สในหมวดที่เลือก และมีการค้นหากับเรียงลำดับเพิ่มให้ใช้งานสะดวกขึ้นครับ”

## 1:00–1:35 — รายละเอียดคอร์ส

เปิด React.js for Beginners แสดงคำอธิบายและ 4 บทเรียน

พูด:

“หน้าคอร์สแสดงชื่อ คำอธิบาย และรายการบทเรียน พร้อมเวลาแต่ละบทและเวลารวม ข้อมูลส่วนนี้ผ่าน Class Course และ Lecture เพื่อจัดรูปแบบและคำนวณเวลาเรียนครับ”

## 1:35–2:25 — วิดีโอและสถานะเรียนจบ

เปิด Components & Props กด Play ให้เห็นวิดีโอ เปลี่ยนไปอีกบท แล้วกด “ทำเครื่องหมายว่าเรียนจบ”

พูด:

“ทุกบทสามารถเปิดวิดีโอได้ เนื่องจาก API ไม่มี URL วิดีโอ ผมจึงเพิ่มสื่อสาธิตสั้นตามหัวข้อของแต่ละบท เวลาในรายการคือเวลาตามหลักสูตร ส่วนวิดีโอที่เพิ่มมีความยาว 18 วินาทีครับ”

“เมื่อกดเรียนจบ ไอคอนและข้อความจะเปลี่ยน และคำนวณเปอร์เซ็นต์ความคืบหน้าใหม่ กดอีกครั้งเพื่อเปลี่ยนกลับได้ หรือดูวิดีโอจนจบแล้วระบบจะบันทึกให้ครับ”

## 2:25–3:10 — บันทึกเมื่อออกและกลับมา

1. พิมพ์โน้ตในบทเรียน
2. กลับรายละเอียดคอร์ส กดบันทึกคอร์ส
3. เปิดการเรียนของฉัน
4. คัดลอก URL แล้วปิดแท็บ เปิดแท็บใหม่และวาง URL เดิม
5. กลับบทเดิม ตรวจโน้ตและสถานะเรียนจบ

พูด:

“ข้อมูลการเรียน คอร์สที่บันทึก บทล่าสุด และโน้ต เก็บด้วย localStorage เมื่อออกแล้วกลับมาใน Browser เดิม ข้อมูลยังอยู่ ข้อมูลนี้แยกตามอุปกรณ์และ Browser ครับ”

## 3:10–3:45 — รองรับมือถือ

ลดหน้าต่าง Browser ให้แคบ หรือใช้โหมดอุปกรณ์มือถือใน Developer Tools แล้วเปิดหน้าคอร์สและห้องเรียน

พูด:

“หน้าจอปรับตามขนาดอุปกรณ์ บนมือถือคอร์สแสดงเป็นคอลัมน์เดียว และรายการบทเรียนย้ายลงใต้พื้นที่วิดีโอเพื่อให้อ่านและกดใช้งานได้ครับ”

## 3:45–4:30 — โครงสร้างโค้ด

เปิด VS Code แสดงไฟล์:

- `src/models/Course.js`
- `src/models/Lecture.js`
- `src/services/CourseApi.js`
- `src/services/ProgressStore.js`

พูด:

“ข้อมูลจาก API ถูกแปลงเป็น Class Model ก่อนนำไปใช้ใน Component มี Course สำหรับคอร์ส และ Lecture สำหรับบทเรียน ส่วน CourseApi จัดการการร้องขอข้อมูล และ ProgressStore จัดการการอ่านและบันทึกข้อมูลใน Browser ครับ”

แสดง `npm run test` และ `npm run build` หากมีเวลา

## 4:30–4:50 — ปิดการนำเสนอ

แสดง Repository **Public** ที่คุณอัปโหลดจริง

“โปรเจกต์นี้มีฟังก์ชันหลักตามโจทย์ และเพิ่มค้นหา เรียงลำดับ บันทึกคอร์ส กลับมาเรียนต่อ และจดโน้ต โค้ดอยู่ใน GitHub Repository แบบ Public ตามลิงก์ที่ส่งครับ ขอบคุณครับ”
