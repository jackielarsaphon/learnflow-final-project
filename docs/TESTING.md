# สถานะการตรวจโปรเจกต์

ตรวจเมื่อ 14 ตุลาคม 2026

## ผ่านการตรวจอัตโนมัติ

- 13 tests ผ่านด้วย `npm run test`
- ทดสอบ HTTP กับ Mock API ต้นฉบับจริง ครบ /courses, /courses/:id, /categories และหมวดหมู่ Data Science
- ทดสอบ Model คำนวณเวลาเรียนและแปลง Lecture
- ทดสอบบันทึกข้อมูลแล้วสร้าง ProgressStore ใหม่ เพื่อจำลองการกลับมาเปิด Browser
- ทดสอบย้อนสถานะเรียนจบ บทที่ไม่มีอยู่ ความคืบหน้า 100% และข้อมูลเก่า
- ทดสอบข้อมูลเสียและ Browser Storage ถูกปิด
- ทดสอบ Render หน้า Catalog, Detail, Classroom และ My Learning ด้วย React
- วิดีโอทุกบทตรวจด้วย ffprobe: H.264, yuv420p, 1280×720, 18 วินาที
- ตรวจภาพตัวอย่างวิดีโอว่าอ่านภาษาไทยได้
- Production build ผ่าน

## สิ่งที่ยังต้องทดลองบน Browser จริงก่อนส่ง

การตรวจครั้งนี้ไม่ได้ทดลองคลิกบน Browser จริง จึงเตรียมขั้นตอนให้ผู้เรียนตรวจและใช้อัดวิดีโอในคราวเดียวกัน

| ขั้นตอน | ผลที่ควรเห็น |
| --- | --- |
| เปิดหน้าหลัก | 8 คอร์ส, 4 หมวดหมู่, 25 บท |
| เลือก Programming | JavaScript, React และ Next.js รวม 3 คอร์ส |
| เลือก Design | UI/UX และ Figma รวม 2 คอร์ส |
| ค้นหา react | เหลือ React.js for Beginners |
| ค้นหาคำที่ไม่มี | Empty State และปุ่มล้างตัวกรอง |
| เลือกเวลาเรียนน้อยที่สุด | UI/UX 110 นาทีอยู่ก่อนคอร์สที่เวลามากกว่า |
| บันทึก Figma | ไอคอนเปลี่ยน และพบใน “บันทึกไว้” |
| เปิด React.js for Beginners | 4 บท และเวลา 3 ชม. 40 นาที |
| เปิด Components & Props | วิดีโอ 2-2 และ Sidebar ตรงกับบท |
| กด Play | เล่นวิดีโอแบบ Concept → Example → Takeaway |
| ดูวิดีโอจนจบ | บท 2-2 ถูกทำเครื่องหมายเรียนจบอัตโนมัติ |
| กดปุ่มเรียนจบซ้ำ | เปลี่ยนกลับเป็นยังไม่เรียน |
| จดโน้ต | เปลี่ยนบทแล้วกลับมา โน้ตยังอยู่ |
| ปิดและเปิดเว็บใหม่ | บทที่จบ คอร์สที่บันทึก และโน้ตยังอยู่ |
| เรียนครบ 4 บท React | เห็น 100% และอยู่ใน “เรียนครบแล้ว” |
| เปิดลิงก์ #/courses/unknown | แสดงไม่พบคอร์ส มีทางกลับหน้าหลัก |
| หน้าจอ 390px และ 1440px | อ่านได้ ปุ่มกดได้ หน้าไม่ล้นแนวนอน |
| ใช้ปุ่ม Tab และ Enter | เข้าเมนู ตัวกรอง เปิดบท และกดเรียนจบได้ |
| หยุด Mock API แล้ว Refresh ตอน dev | เห็น Error และลองโหลดอีกครั้งได้ |

ไม่ควรเพิ่มเครื่องหมาย “ผ่าน” ให้รายการทดลอง Browser จนกว่าจะได้ทดลองจริง
