## คำอธิบายโปรเจกต์

LearnFlow เป็นเว็บเรียนออนไลน์ที่พัฒนาด้วย React รองรับ Mobile และ Desktop ผู้ใช้เลือกคอร์สตามหมวดหมู่ ดูรายละเอียดและวิดีโอแต่ละบท ทำเครื่องหมายว่าเรียนจบ และติดตามความคืบหน้าได้ ข้อมูลคอร์สดึงจาก API ที่กำหนดและแปลงผ่าน Class Model ข้อมูลการเรียนบันทึกด้วย localStorage เพื่อให้กลับมาใช้งานต่อได้

ฟังก์ชันเพิ่มเติมคือการค้นหา เรียงลำดับ Bookmark คอร์ส หน้าการเรียนของฉัน Resume บทล่าสุด Notes และบันทึกเรียนจบอัตโนมัติเมื่อวิดีโอจบ

## ก่อนกดส่ง

- Repository ตั้งค่า Public แล้ว และเปิดดูได้โดยไม่ Login
- README มีวิธีติดตั้งและใช้เว็บ
- โค้ด Source, package.json, package-lock.json และวิดีโอบทเรียนอยู่ใน Repository
- ไม่อัปโหลด node_modules หรือ Secret
- วิดีโอส่งงานแสดงการใช้เว็บจริง ไม่ใช่เพียงวิดีโอบทเรียน
- แสดงการออกแล้วเข้าใหม่ว่าข้อมูลยังอยู่
- ทดลองหน้าจอ Mobile และ Desktop จริงแล้ว
- ใช้คำอธิบายที่คุณเข้าใจ และอธิบาย Class Model กับการบันทึกข้อมูลได้

เงื่อนไข Certificate และ Final Quiz เป็นส่วนที่ผู้เรียนต้องดำเนินการตามเกณฑ์ของผู้สอนเอง
